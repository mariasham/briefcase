# Briefcase

Briefcase is a Node.js and Express web version of my Project 1 Law School
Application Tracker. It helps applicants organize schools, track decisions,
save favorites, and keep notes for individual applications.

## Run locally

Requires Node.js 24. From the project folder:

```sh
npm ci
npm start
```

Open http://localhost:3000.

## Checks

```sh
npm run check
npm test
```
