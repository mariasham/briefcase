# Product Backlog

| Priority | Feature | Done when |
| --- | --- | --- |
| 1 | Applications list and details | An applicant can browse and search schools and view each school's location, deadline, status, and application link. |
| 2 | Add applications | A valid new application appears immediately in the list and is still there after reopening the app. |
| 3 | Track status | An applicant can save and filter by Planning, In Progress, Applied, Accepted, Waitlisted, or Rejected. |
| 4 | Favorites | An applicant can star or unstar a school and see starred schools on a dedicated Favorites page. |
| 5 | Application notes | An applicant can save dated notes on a specific application and see them when reopening it. |
| 6 | Explore Schools | An applicant can browse U.S. law schools on a map and add a school to the tracker. |
| 7 | Admissions research | School profiles show available acceptance rates, median LSAT and GPA, tuition, and cost of attendance with sources and reporting years. |
